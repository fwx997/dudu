## 技术实现要点

### 配置管理
- 使用 UserDefaults 存储用户偏好设置
- 创建 AppSettings 单例管理全局配置
- 支持配置导入/导出

### 搜索过滤
- 在 SearchViewModel 中添加过滤逻辑
- 支持正则表达式匹配
- 支持模糊搜索算法

### 文本转换
- 使用 Core Foundation 的 CFStringTransform
- 支持简繁体互转
- 缓存转换结果提升性能

### 界面状态管理
- 使用 @AppStorage 绑定设置项
- 支持实时预览设置效果
- 保存用户自定义主题
